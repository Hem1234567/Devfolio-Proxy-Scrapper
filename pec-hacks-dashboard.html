This is organizer-only data protected by a session cookie. Browsers won't let a webpage attach a cookie header to its own requests, so the fix is a tiny local proxy that runs on your machine, attaches your cookie server-side, and hands data back to this page over localhost.
1. Download proxy.py (linked below the dashboard). Open it in any text editor.
2. In DevTools → Network → click an api.devfolio.co request → Headers → Request Headers → copy the full cookie value.
3. Paste it as the COOKIE value near the top of proxy.py, save the file.
4. Run python3 proxy.py in a terminal and leave that window open.
5. Come back here and hit Connect below.
Only use this if your auth actually turns out to be a bearer token rather than a cookie (rare for this API, but here in case): paste the header value below and it'll be attached directly, no proxy needed.
